# Web Data Collection and Comparative Analysis Using World Bank Data

## 📌 Project Overview

This project focuses on collecting, processing, and analyzing real-world data from the **World Bank API** to compare Switzerland and Austria over the period **2000–2023**.

The analysis examines three important indicators: Population, GDP per Capita, and Life Expectancy. Using Python and data science libraries, the project explores historical trends, identifies differences between the two countries, and presents findings through data visualizations.

## 🎯 Project Objectives

- Collect real-world statistical data using the World Bank API.
- Process and clean the collected datasets using Pandas.
- Analyze population growth, economic performance, and life expectancy.
- Compare historical trends between Switzerland and Austria.
- Present analytical findings through charts and visualizations.

## 📊 Dataset Information

**Data Source:** [World Bank Open Data](https://data.worldbank.org/)

**Countries:**
- Switzerland (CHE)
- Austria (AUT)

**Time Period:** 2000–2023

**Indicators:**

| Indicator | Indicator Code |
|---|---|
| Population, Total | SP.POP.TOTL |
| GDP per Capita (Current US$) | NY.GDP.PCAP.CD |
| Life Expectancy at Birth | SP.DYN.LE00.IN |

## ⚙️ Project Workflow

### 1. Data Collection
- Sent HTTP GET requests to the World Bank API.
- Collected data for two countries and three indicators.
- Used exception handling to manage request errors.
- Collected 144 records through six API requests.

### 2. Data Processing and Cleaning
- Created a structured Pandas DataFrame.
- Converted data types into appropriate formats.
- Checked missing values and duplicate records.
- Removed duplicate and incomplete records where necessary.
- Exported the cleaned dataset as a CSV file.

### 3. Comparative Data Analysis
Performed analysis to answer three main research questions:

- Which country experienced greater population growth?
- Which country had higher GDP per capita, and how did the difference change?
- Which country experienced greater improvement in life expectancy?

### 4. Data Visualization
Created line charts and bar charts to illustrate:
- Population trends over time.
- Population growth index.
- GDP per capita trends.
- Life expectancy trends.
- GDP per capita differences.
- Population growth percentage.
- Life expectancy improvements.

## 📈 Key Findings

Based on the notebook's analysis for 2000–2023:

- **Population:** Switzerland experienced higher population growth in percentage terms (23.7%) and added more people in absolute numbers.
- **GDP per Capita:** Switzerland had a higher GDP per capita in 2023. The gap increased from approximately $14,811 to $47,870.
- **Life Expectancy:** Switzerland experienced a greater improvement in life expectancy, increasing by approximately 4.48 years.

These findings highlight differences in demographic growth, economic performance, and life expectancy between the two countries.
